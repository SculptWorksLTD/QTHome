# QTHome — 使用手册

QTHome 是管理整个电台的程序：电台、日志、CW、数字模式、集群、SDR、卫星、比赛等等，都在一个窗口里。它在你的电脑上运行，收听和解码无需订阅。

## 安装

- **Mac**：下载 `QTHome-Mac.pkg`，打开并按步骤操作。QTHome 会出现在“应用程序”中。
- **Windows**：下载 `QTHome-Windows.zip`，打开后把 `QTHome.exe` 拖到你喜欢的位置（例如桌面），然后打开它。

QTHome 会自动更新：有新版本时会下载，并在关闭时安装。

## 第一次使用

1. 用 USB 线把电台连到电脑并打开电台。
2. 打开 QTHome：电台会自动出现在 **电台** 面板中（内置的 The Rigger 会识别电台）。
3. 点击右上角的 **呼号？**，填写你的呼号和网格。
4. 更换语言：**帮助 › 语言…**

## 窗口

- **顶部**：菜单、电台和 SDR 电视棒的状态、你的呼号和 UTC 时间。
- **电台栏** 始终可见：选择电台，查看和修改频率（VFO A 和 B）及模式，按 **PTT · TX** 发射（3 分钟后自动停止）。
- **左边** 是各部分，**右边** 是所选面板。尚未完成的部分标有“即将推出”。
- 所有功能都可以用键盘和读屏软件操作；**帮助 › 语音** 会朗读频率、模式和信号。

## 各部分

- **电台**：已连接的电台、大字频率、S 表、快速记录 QSO。WSJT-X、fldigi、JS8Call 等程序通过 QTHome 连接电台：方法见“如何把程序连接到”。
- **旋转器**：连接旋转器（Yaesu GS-232 或 Hamlib rotctld），按角度或朝某个网格转动，也支持长路径。
- **日志**：所有 QSO，ADIF 导出和导入。下方是 **电子 QSL**：LoTW（需要免费的 TQSL）、eQSL、QRZ Logbook 和 Club Log；密码只保存在你的电脑上。
- **话音**:收听与录音,最近 60 秒随时可保存,4 个可发射的语音存储(F1-F4)。**FreeDV**(700D、700E、700C、1600):从电台音频收听,「按住说话」。**Pi-Star / WPSD**:经过你的 DMR、D-STAR、YSF 热点的电台,一键放入 QSO 栏。
- **CW**：CWEngine 解码器、电键、消息、使用 SDR 电视棒的掠读器。CW 解码永久免费。
- **数字模式**:像 WSJT-X 一样的 FT8 和 FT4(接收和发射)、RTTY、PSK、APRS、WSPR、Hell、QRSS 和 SSTV。Q65、MSK144 和 JT65 通过旁边打开的 WSJT-X(「通过 WSJT-X 的其他模式」框)。
- **集群与传播**：带筛选的 DX 集群和 Reverse Beacon Network；点击 spot 电台就会调过去。太阳数据和波段状况。
- **SDR**：RTL-SDR 电视棒接收机，频谱和瀑布图；点击即可收听某个频率。
- **卫星与太空**：下一次过境、多普勒、旋转器跟踪和电台校正。
- **远程与自动化**：在家庭网络中用手机通过 PIN 使用 QTHome。在你允许之前，远程发射一直关闭。
- **比赛**：ARI DX、CQ WW、CQ WPX、IARU HF、VHF 和通用比赛；序号、重复、Cabrillo。Enter 记录，Esc 清除。
- **QTHome Chat**:火腿之间的文字和语音房间;服务器上不留任何内容。
- **Winlink**:通过互联网或用 VARA 调制解调器(需另装)经电台收发邮件:收件、发件、写邮件。Winlink 密码只保存在你的电脑上。
- **地图**和**工具**:此刻的世界(spot、谁听到你、晨昏线、电离层测高仪)和电台计算工具。
- **AI 助手**：写下你想做的事（“把电台调到 14.074 FT8”、“ISS 什么时候过境”、“QSB 是什么意思”）。它在电脑上运行，无需网络，从不发射。

## 出现问题时

- **电台没有出现**：检查 USB 线和电台是否打开；然后 **电台 › 重新查找电台**。
- **没有声音**：在 Mac 上，到“系统设置 › 隐私与安全性”允许 QTHome 使用麦克风。
- **报告问题**：**帮助 › 报告问题或想法…** 匿名发送，不含呼号、姓名或地址。
