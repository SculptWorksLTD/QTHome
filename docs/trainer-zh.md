# QTHome Trainer — 测试者指南

QTHome Trainer 在你像平常一样使用 WSJT-X 时一起收听你的电台，并把 QTHome 的 FT8/FT4 解码器与 WSJT-X 的进行比较。这样我们就能看到自己的解码器在哪里出错，并加以改进。

**它从不发射，也从不控制电台。** 它只读取音频。

## 需要什么

- 一台 Mac（Apple 或 Intel）或一台 Windows 10/11 电脑。
- 通过 USB 声卡连接到电脑的电台（就是你用于 WSJT-X 的那个）。
- **已安装 WSJT-X**（免费：<https://wsjt.sourceforge.io/wsjtx.html>）。Trainer 以它的解码器为参照，不需要打开它。

## 安装

1. 打开发布页面：<https://github.com/SculptWorksLTD/QTHome/releases/latest>
2. 下载 **QTHome-Trainer-Mac.pkg**（Mac）或 **QTHome-Trainer-Windows.zip**（Windows）。
3. Mac：双击 .pkg。如果 Mac 拒绝打开：右键点击文件 → **打开**。
   Windows：打开 zip 并启动 **QTHome Trainer.exe**。如果 Windows 警告：**更多信息 → 仍要运行**。

## 第一次使用

1. 填写你的 **网格**（4 或 6 个字符，例如 JN45ab）：只使用大致区域。
2. 勾选你用什么接收以及你的天线。
3. 决定是否发送 **音频片段**（请阅读说明框）：它们帮助很大，但你也可以拒绝。
4. **保存并开始**。

## 每次使用

1. 选择 **电台音频输入**（例如“USB Audio CODEC”）。
2. 按 **开始收听**。在 Mac 上，第一次系统会请求麦克风权限：选择 **允许**。
3. 把电台调到 FT8 频率（例如 14.074 MHz USB），让它运行。

每个 15 秒时隙结束时会显示一个表格：每条消息如果 QTHome 解出就打 ✓，WSJT-X 解出也打 ✓。

如果窗口无法使用音频，会出现 **在浏览器中打开** 按钮：Trainer 会在浏览器中打开，那里麦克风总能使用。

## 电台的 CW

在 **设置** 中勾选 **CW**，然后在电台声卡上按 **开始收听**。像平常一样收听 CW：每 30 秒，QTHome 的两个解码器会重读你听到的内容，并用 Reverse Beacon Network（RBN）核对呼号。如果 The Rigger 正在运行，Trainer 还知道你所在的波段。只发送有用的情况：RBN 从未听到过的呼号，或两个解码器结果不一致。

## 用 SDR 电视棒做掠读器（目前仅限 Mac）

需要一根接了 HF 天线的 RTL-SDR V3 或 V4 电视棒（电台保持空闲）。勾选 **用 SDR 电视棒做掠读器**，选择波段并按 **打开掠读器**：电视棒会自己寻找。它会转到 RBN 和频谱显示电台最多的波段，同时读取所有电台，一旦没有新呼号出现就换波段。选的波段越多，测试次数越多。呼号与 RBN 比对；表格中 ✓ 表示已确认，? 表示 RBN 从未听到。

## 发送给 QTHome 的内容

- 只有有用的情况：弱信号、拥挤的波段、只有一个解码器解出的消息。
- **从不发送你的呼号**，也不发送 IP 地址、电脑名称或个人文件夹。
- 只有在你同意时才发送 15 秒的音频片段，每小时最多 6 个，12 个月后删除。

## 出现问题时

按右上角的 **报告**，描述发生的情况并发送。这是匿名的；没有网络时会排队等待。
