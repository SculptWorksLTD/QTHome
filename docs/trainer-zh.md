# QTHome Trainer — 测试者指南

QTHome Trainer 在你照常使用电台时和你一起收听，并把 QTHome 的 FT8/FT4 解码器
与 WSJT-X 进行对比。这样我们能看到自己的解码器在哪里出错，并加以改进。

**它从不发射，也从不控制电台。** 它只读取音频。

## 需要什么

- 一台 Mac（Apple 或 Intel）或 Windows 10/11 电脑。
- 用 USB 线连接到电脑的电台（它的声卡，例如“USB Audio CODEC”）。
- 别的都不需要：对比所需的 WSJT-X 工具由 Trainer 自动下载一次。

## 安装

1. 打开发布页面：<https://github.com/SculptWorksLTD/QTHome/releases/latest>
2. 下载 **QTHome-Trainer-Mac.pkg**（Mac）或 **QTHome-Trainer-Windows.zip**（Windows）。
3. Mac：双击 .pkg。若 Mac 拒绝打开：右键点击文件 → **打开**。
   Windows：打开 zip 并运行 **QTHome Trainer.exe**。若 Windows 警告：**更多信息 → 仍要运行**。

## 第一次使用

会打开一个 5 步向导：

1. **欢迎**：Trainer 做什么。
2. **你的电台**：网格定位（4 或 6 位，例如 JN45ab，只用于区域）、电台、天线。
3. **电台音频**：选择电台的声卡并调到 FT8 频率（例如 14.074 MHz USB）。电平应处于绿色区域。在 Mac 上第一次会请求麦克风权限：请选择 **允许**。
4. **隐私**：我们发送什么，以及你是否愿意发送音频片段。
5. **一切就绪**：按 **开始接收**。

## 窗口

- **概览**：收听（输入、带建议的电平、频谱）、**电台状态**（音频、与 WSJT-X 对比、电台、时钟、上传）和你的数字。顶部四个指示灯一眼就能看出同样的信息：绿色正常，黄色需查看，红色需处理。
- **FT8 · FT4**：每个时隙中 QTHome 和 WSJT-X 读到的消息（绿 = 两者都读到，红 = 仅 WSJT-X，黄 = 仅 QTHome）以及最近时隙的一致率。
- **CW** 和 **掠读器**：见下文。
- **设置**：收听内容、电脑占用、音频片段、电台资料、更新。

使用电台时请保持 Trainer 打开（可最小化）：每次启动都会自动继续收听。
电脑时钟会通过互联网校验：如有偏差，Trainer 会自动校正时隙的切分。

## 电台 CW

在 **CW** 标签中勾选 **读取电台 CW**（收听已开启）。像平时一样收听 CW：每 30 秒，QTHome 的两个解码器
重读你听到的内容，并用 Reverse Beacon Network (RBN) 核对呼号。若 The Rigger 正在运行，Trainer 还能知道你的波段，核对更准确。

## 用 SDR 电视棒做掠读器（目前仅限 Mac）

需要一只接上短波天线的 RTL-SDR V3 或 V4（电台保持空闲）。
在 **设置** 中勾选 **用 SDR 电视棒做掠读器**，然后在 **掠读器** 标签中选择波段并按 **打开掠读器**：
电视棒会自己寻找 RBN 和频谱显示电台最多的地方。表中 ✓ 表示已被 RBN 确认，? 表示 RBN 从未听到。

## 发送给 QTHome 的内容

- 只有有用的案例：弱信号、拥挤的波段、只被其中一个解码器读到的消息。
- **绝不发送你的呼号**，也绝不发送 IP 地址、电脑名称或个人文件夹。
- 15 秒音频片段仅在你同意时发送，每小时最多 6 个，12 个月后删除。
- 若上传尚未开启或没有网络，案例会在电脑上等待，之后自动发送：状态中的 **上传** 一行始终说明当前情况。

## 遇到问题

点击右上角的 **反馈**，描述发生了什么并发送。内容是匿名的；没有网络时会排队，稍后发送。
