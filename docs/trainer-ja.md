# QTHome — ベータテスター向けガイド

別のプログラムはもう不要です：Trainer の役割は QTHome が行います。

## オンにする方法

1. QTHome を開き、**設定 › CW の改善に協力** へ。
2. **CW の改善に協力（匿名）** にチェック。
3. **無線機のオーディオ入力**（例「USB Audio CODEC」）を選びます。
4. 必要なら、疑わしい例の**音声クリップ**の送信も許可します。

あとはいつも通り CW を聞くだけです。30 秒ごとに QTHome の 2 つのデコーダーが受信内容を読み直し、コールサインを
Reverse Beacon Network (RBN) と照合します。CW 機能のスキマー（SDR ドングル）がオンなら、そのコールサインも 2 分ごとに照合します。
**送信も無線機の操作もしません。**

FT8 と FT4 は不要になりました：QTHome は初回に自動でダウンロードする WSJT-X のエンジンでデコードします。

## QTHome に送られるもの

- 役立つ例だけ：2 つのデコーダーの不一致、RBN が聞いたことのないコールサイン、読めなかった強い局。
- **コールサイン、IP アドレス、パソコン名、個人フォルダーは送りません**。ロケーターは 4 文字のみ。
- 音声クリップは同意した場合のみ、1 時間に最大 6 件、12 か月後に削除。
- 送信がまだ有効でない、またはインターネットがない場合、例はパソコンで待機し後で自動送信されます。
