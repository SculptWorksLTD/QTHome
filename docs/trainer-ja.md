# QTHome Trainer — ベータテスター向けガイド

QTHome Trainer は、あなたがいつも通り無線機を使っている間に一緒に受信し、
QTHome の FT8/FT4 デコーダーを WSJT-X と比べます。こうして私たちのデコーダーが
どこで間違えるかを知り、改善します。

**送信も無線機の操作も一切しません。** 音声を読むだけです。

## 必要なもの

- Mac（Apple または Intel）または Windows 10/11 のパソコン。
- USB ケーブルでパソコンにつないだ無線機（そのサウンドカード、例「USB Audio CODEC」）。
- それだけです：比較に使う WSJT-X のツールは Trainer が初回に自動でダウンロードします。

## インストール

1. リリースページを開きます：<https://github.com/SculptWorksLTD/QTHome/releases/latest>
2. **QTHome-Trainer-Mac.pkg**（Mac）または **QTHome-Trainer-Windows.zip**（Windows）をダウンロード。
3. Mac：.pkg をダブルクリック。開けないと言われたら、ファイルを右クリック → **開く**。
   Windows：zip を開いて **QTHome Trainer.exe** を起動。警告が出たら **詳細情報 → 実行**。

## 初回

5 ステップのガイドが開きます：

1. **ようこそ**：Trainer の役割。
2. **あなたの局**：ロケーター（4 または 6 文字、例 JN45ab。地域だけを使います）、無線機、アンテナ。
3. **無線機の音声**：無線機のサウンドカードを選び、FT8 周波数（例 14.074 MHz USB）に合わせます。レベルは緑の範囲に。Mac では初回にマイクの許可を求められます：**許可** を選んでください。
4. **プライバシー**：送る内容と、音声クリップを送るかどうか。
5. **準備完了**：**受信を開始** を押します。

## ウィンドウ

- **概要**：受信（入力、アドバイス付きレベル、スペクトラム）、**ステーションの状態**（音声、WSJT-X との比較、無線機、時計、送信）とあなたの数字。上部の 4 つのランプも同じことを示します：緑は良好、黄は確認、赤は要対処。
- **FT8 · FT4**：スロットごとに QTHome と WSJT-X が読んだメッセージ（緑 = 両方、赤 = WSJT-X のみ、黄 = QTHome のみ）と直近の一致率。
- **CW** と **スキマー**：下記参照。
- **設定**：受信する内容、パソコンの使用、音声クリップ、局のプロフィール、アップデート。

無線機を使う間は Trainer を開いたままに（最小化可）：起動のたびに自動で受信を再開します。
パソコンの時計はインターネットで確認され、ずれていれば Trainer がスロットの切り出しを自動で補正します。

## 無線機の CW

**CW** タブで **無線機の CW を読む** にチェック（受信中）。いつも通り CW を聞いてください：30 秒ごとに
QTHome の 2 つのデコーダーが聞いた内容を読み直し、コールサインを Reverse Beacon Network (RBN) と照合します。
The Rigger が動いていればバンドも分かり、照合がより正確になります。

## SDR ドングルでスキマー（現在は Mac のみ）

HF アンテナをつないだ RTL-SDR V3 または V4 が必要です（無線機は空いたまま）。
**設定** で **SDRドングルでスキマー** にチェックし、**スキマー** タブでバンドを選んで **スキマーをオン** を押します：
ドングルは RBN とスペクトラムで局の多い所を自分で探します。表の ✓ は RBN で確認済み、? は RBN で未確認。

## QTHome に送られるもの

- 役立つ例だけ：弱い信号、混雑したバンド、片方のデコーダーだけが読んだメッセージ。
- **コールサインは送りません**。IP アドレス、パソコン名、個人フォルダーも送りません。
- 15 秒の音声クリップは同意した場合のみ、1 時間に最大 6 件。12 か月後に削除されます。
- 送信がまだ有効でない、またはインターネットがない場合、例はパソコンで待機し後で自動送信されます：状態の **送信** 行が常に現状を示します。

## テスター向け無料ライセンス

概要に **受信時間**、ライセンスまでのバー、**テスターコード**（QT-XXXX-XXXX、匿名）が表示されます。[Beta tester](https://iu1mvi.jimdofree.com/beta-tester/) ページのフォームにコールサインと一緒に入力してください。

- 受信 **10 時間**：QTHome PRO が 1 年間無料。
- 3 か月以上にわたり **100 時間**：ファウンダーライセンス、PRO が永久無料。

無線機がオンで信号が届いている時間だけが数えられます。

## 問題があったら

右上の **報告** を押し、何が起きたかを書いて送信します。匿名で届きます。インターネットがなければ待機し、後で送信されます。
