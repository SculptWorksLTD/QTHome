# QTHome — マニュアル

QTHomeは局全体のためのソフトです。無線機、ログ、CW、デジタルモード、クラスター、SDR、衛星、コンテストなどを1つのウィンドウで扱えます。コンピューター上で動き、受信と解読には料金はかかりません。

## インストール

- **Mac**：`QTHome-Mac.pkg` をダウンロードして開き、手順に従います。QTHomeは「アプリケーション」に入ります。
- **Windows**：`QTHome-Windows.zip` をダウンロードして開き、`QTHome.exe` を好きな場所（たとえばデスクトップ）にドラッグしてから開きます。

QTHomeは自動で更新されます。新しいバージョンが出るとダウンロードし、終了するときにインストールします。

## はじめて使うとき

1. USBケーブルで無線機をコンピューターにつなぎ、電源を入れます。
2. QTHomeを開くと、無線機が自動で **ステーション** 画面に表示されます（無線機を認識するThe Riggerが内蔵されています）。
3. 右上の **コールサイン？** をクリックし、コールサインとロケーターを入力します。
4. ほかの言語にするには：**ヘルプ › 言語…**

## ウィンドウ

- **上**：メニュー、無線機とSDRドングルの状態、コールサイン、UTC時刻。
- **無線機バー** はいつも表示されています。無線機を選び、周波数（VFO AとB）とモードを確認・変更し、**PTT · TX** を押すと送信します（3分で自動停止）。
- **左** に各画面、**右** に選んだ画面。まだ準備中の画面には「近日公開」と表示されます。
- キーボードとスクリーンリーダーでもすべて操作できます。**ヘルプ › 音声** で周波数、モード、信号を読み上げます。

## 各画面

- **ステーション**：接続中の無線機、大きな周波数表示、Sメーター、QSOのクイック入力。WSJT-X、fldigi、JS8CallなどのソフトはQTHome経由で無線機につながります。方法は「ソフトをつなぐ方法」にあります。
- **ローテーター**：ローテーター（Yaesu GS-232 または Hamlib rotctld）をつなぎ、角度やロケーターの方向へ向けます。ロングパスも可能です。
- **ログ**：すべてのQSO、ADIFの書き出しと読み込み。下に **電子QSL**：LoTW（無料のTQSLが必要）、eQSL、QRZ Logbook、Club Log。パスワードはコンピューターにだけ保存されます。
- **電話**：受信と録音、直近60秒はいつでも保存可能、送信用の音声メモリー4つ(F1-F4)。**FreeDV**(700D、700E、700C、1600):無線機の音声から受信、「押している間に話す」。**Pi-Star / WPSD**:DMR、D-STAR、YSFのホットスポットを通った局を、クリックでQSOバーへ。
- **CW**：CWEngineデコーダー、キーヤー、メッセージ、SDRドングルのスキマー。CWの解読はずっと無料です。
- **デジタルモード**：WSJT-Xと同様のFT8・FT4(受信と送信)、RTTY、PSK、APRS、WSPR、Hell、QRSS、SSTV。Q65、MSK144、JT65は隣で開いたWSJT-X経由(「WSJT-Xでほかのモード」)。
- **クラスターと伝搬**：フィルター付きのDXクラスターとReverse Beacon Network。スポットをクリックすると無線機がそこへ移ります。太陽データとバンドコンディション。
- **SDR**：RTL-SDRドングルの受信機、スペクトルとウォーターフォール。クリックでその周波数を聞けます。
- **衛星と宇宙**：次のパス、ドップラー、ローテーターでの追尾と無線機の補正。
- **リモートと自動化**：自宅ネットワーク内のスマホからPIN付きでQTHomeを使えます。リモート送信は許可するまでオフです。
- **コンテスト**：ARI DX、CQ WW、CQ WPX、IARU HF、VHF、汎用。シリアル、重複、Cabrillo。Enterで記録、Escでクリア。
- **QTHome Chat**：OM同士のテキストと音声のルーム。サーバーには何も残りません。
- **Winlink**：インターネットまたはVARAモデム(別途インストール)による無線でのメール:受信、送信、作成。Winlinkのパスワードはこのコンピューターにだけ保存されます。
- **地図**と**ツール**：いまの世界(スポット、あなたを受信している局、グレイライン、イオノゾンデ)と局の計算ツール。
- **AIアシスタント**：してほしいことを書きます（「無線機を14.074 FT8に」「ISSはいつ通る」「QSBの意味は」）。コンピューター上でインターネットなしで動き、送信はしません。

## 無料とPRO

受信、解読、ログはいつでも無料です。QTHomeからの送信、自動化、高度なコンテスト機能、オンラインQSLはPROの機能です。最初の30日間はすべて試せます。PROは **年12ユーロ** で、サーバーと研究開発の費用にあてられます。

## うまくいかないとき

- **無線機が表示されない**：USBケーブルと無線機の電源を確認し、**ステーション › 無線機をもう一度探す**。
- **音が出ない**：Macでは「システム設定 › プライバシーとセキュリティ」でQTHomeのマイクを許可します。
- **問題を送る**：**ヘルプ › 問題やアイデアを送る…** コールサイン、名前、住所を除いて匿名で送られます。
