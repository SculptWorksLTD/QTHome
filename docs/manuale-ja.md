# QTHome — マニュアル

QTHome は局全体のためのプログラムです。無線機、ログ、CW、デジタルモード、クラスター、SDR、衛星、コンテストなどを一つのウィンドウで扱います。プログラムは一つだけ：無線機、コールサイン、現在のQSO、ログはどのセクションでも共通です。受信とデコードは無料です。

## インストール

- **Mac**：`QTHome-Mac.pkg` をダウンロードして開き、手順に従ってください。QTHome は「アプリケーション」に入ります。
- **Windows**：`QTHome-Windows.zip` をダウンロードして開き、`QTHome.exe` を好きな場所（例えばデスクトップ）にドラッグしてから開いてください。

QTHome は自動で更新されます。新しいバージョンがあればダウンロードし、終了時にインストールします。

## 最初に

1. 無線機をUSBケーブルでコンピューターに接続し、電源を入れます。
2. QTHome を開く：**ようこそ画面**が最初の手順を説明します（不要になったら「今後表示しない」にチェック）。続いて**コールサインとロケーター**を聞かれます。すべての機能で使われます。
3. 無線機は自動で表示されます。**局** の **はじめに** カードに、足りないもの（無線機、オーディオ、クラスター）と設定ボタンが表示されます。
4. Mac では、最初に無線機の音を聞くときに QTHome の **マイク** を許可してください。無線機からの音声です。
5. 別の言語にするには：**設定 › 外観、言語、アクセシビリティ**。

## ウィンドウ

- **上部**：メニュー、無線機とSDRドングルの状態、コールサイン、UTC時刻。 **ウォーターフォール**：各ウォーターフォールの横の「調整」で自動レベル、明るさ、コントラスト、色、高さを変更。
- **無線機バー** は常に表示：無線機、バンド、周波数（VFO A と B）、モード、フィルター、**PTT · TX**（誰が操作しても無線機が送信中なら赤；3分で自動的に解除）、そしてフロントパネルの全操作を持つ **無線機の操作**。
- **左側**に各画面。標準では基本の画面だけを表示し、ほかは **+ その他の機能** にあります（常にすべて表示するには：**設定 › 外観、言語、アクセシビリティ**）。
- **下にウォーターフォール**：QSO バーの上、局・ログ・電話・コンテスト・クラスター・地図・衛星・ローテーターで表示。「カスケード」をクリックすると折りたためます。
- **見つからないときは** ⌘K（Windows は Ctrl+K）で検索が開きます。「SSTV」「ローテーター」「HamQTH」「ライセンス」などと入力して Enter。
- **下部のQSOバー**：現在のQSO。プログラム全体で一つです。コールサインを入力（Alt+Q でどこからでも移動）、レポート、名前、ロケーター；周波数、バンド、モードは無線機から取ります。国、距離、方位、今どのバンドで聞こえているか、交信済みかを表示します。**Enter** でログに保存、**Esc** でやり直し。 送信中は **Esc** ですべての送信（FT8、フォーン、CW、PTT）を停止します（ステーション › すべての送信を停止 と同じ）。 メモに「POTA IT-0123」「SOTA I/LO-123」「WWFF IFF-0123」と書くと、リファレンスがログの該当欄に入ります。 間違えて保存したら、直後に **取り消し** が出ます。QSO はログから外れ、バーに戻ります。ヨーロッパかアフリカでは、バンドの CW/デジタル部分や 30 m で電話をしていると警告します（IARU バンドプラン）。
- 無線機が接続されていないとき（または **✎** ボタン）は、周波数、モード、日付、UTC時刻を手入力できます。移動運用のQSOを記録するのに便利です。
- クラスター、地図、「今交信できる局」、FT8、RTTY/PSK、CW も現在のQSOを埋めます。スポットをクリックすると無線機が正しい周波数とモードに移り、コールサインがバーに入ります。ローテーターがあれば **↻ ローテーター** でアンテナを相手に向けます。
- すべてキーボードとスクリーンリーダーで操作できます。目の不自由な方は：**設定 › 外観、言語、アクセシビリティ › アクセシビリティをオンにする**（音声アナウンス、モールス、⌘⇧S で S メーター読み上げ）。標準ではオフです。

## セクション

- **局**：大きな周波数表示、Sメーター、PTT、無線機の操作、メモリー（CHIRPとの読み書きも）、今交信できる局、開いているバンド。 **S メーター (dBm)**：設定 › 無線機とプログラムで S 単位と dBm で表示し、既知の信号で校正できます。 自宅ネットワークの **FlexRadio**（SmartSDR）を自動で検出。RepeaterBook の **近くのレピーター**（サイトから書き出したファイル）をワンクリックでメモリーへ。**無線機に書き込む** で Icom に CI-V でメモリーを書き込み（他の無線機やハンディ機は CHIRP で）。**USB パドル**（設定 › アクセサリー）：USB ポートの DTR で無線機をキーイングするエレキー。MIDI パドルも使えます（「パドルを学習」：短点、次に長点を押す）。 **電話から**：設定 › 無線機とプログラム › 電話 で、自宅ネットワーク用のウェブアプリ（PIN 付き）をオン（周波数・バンド・モード、スポット、ログ、新しい QSO。電話からは送信しません）。
- **ログ**：すべてのセクションのQSO。コールサイン、国、バンドで検索；**行をクリック** すると修正・削除できます。紙のQSL（ビューローと直送、印刷用ラベル）と **電子QSL**：LoTW（無料のTQSLが必要）、eQSL、QRZ Logbook、Club Log, HRDLog.net, Wavelog/Cloudlog。アワードと局プロファイル。 公園や山頂から運用するときはプロファイルに参照番号を入力（プロファイル… ›「運用地」）：すべての QSO がログと ADIF に記録します。デジタルモードでは CQ の横のメニューで「CQ POTA」「CQ SOTA」を出せます。 **統計…**：年・バンド・モード・UTC 時刻別の QSO、最多の日、確認済み。 プロファイルには **出力**（W）も入れてください。すべての QSO（TX_PWR）に入り、コンテストの出力部門を選び、統計にワットあたりの記録が出ます。プロファイルごとのエクスポートは POTA と WWFF が求めるファイル名になります。 **アワード…** の「未コンファームのみ」は、コンファームのない交信と QSL を依頼する相手のコールサインを一覧にします。 アワードには ARI の **WAIP** (イタリアの県) もあります。県は QSO (QSO 修正時の県の欄)、ARI コンテストの交換、またはメモの「WAIP-XX」から取ります。 アワードに **WCA**（城）、**ILLW**（灯台）、**JCC**（日本の市）も追加：リファレンスは ADIF の SIG/SIG_INFO かメモ（「WCA I-00123」）から。
- **電話**：受信と録音、直近60秒はいつでも保存可能、音声メモリー4つ（F1-F4）。**FreeDV**（700D、700E、700C、1600）：無線機の音声から受信、「押している間に話す」。**Pi-Star / WPSD**：DMR、D-STAR、YSF のホットスポットを通った局を、クリックで QSO バーへ。
- **CW**：CWEngine デコーダー、キーヤー、メッセージ、SDRドングルのスキマー。オンにすると他のセクションを使っている間も動作します。ここでのQSOは QTHome のログに入ります。CWのデコードはずっと無料です。
- **デジタルモード**：WSJT-X のような FT8 と FT4（自動シーケンス、CQ、自動ログ）、RTTY、PSK31/63、Feld Hell、QRSS（DFCW も）、APRS、WSPR、Q65・JT65・MSK144（WSJT-X のインストール不要）、SSTV（画像：モードは自動判別、受信画像はギャラリーに残ります）。バンドは無線機に追従します。 FT8・FT4・RTTY・PSK のスポットは無線機を正しい位置に合わせ、相手局を入れた状態でデジタルモードを開きます。デコードと QSO は WSJT-X と同じように GridTracker、JTAlert、N1MM、Log4OM にも送れます（設定 › 無線機とプログラム）。 送信をオンにすると、GridTracker や JTAlert で局をダブルクリックするとデジタルモードに準備されます（Tx1 準備完了、送信するかはあなたが決めます）。 自動ハントでは自分あての CQ にだけ応答します：「CQ POTA/SOTA/WWFF」は常に（移動局は毎日あらためて有効）、「CQ DX」は相手が別の大陸のときだけ、「CQ NA」「CQ EU」…は自分の大陸のときだけ、「CQ TEST」はコンテスト開始中だけ。 **WEFAX**：海岸局 (DWD Hamburg、Northwood) の天気図を自動でまっすぐにして保存。 **NAVTEX**：航行警報と海上気象（518 kHz と 490 kHz）、メッセージは種類別に表示。各文字は 2 回送られ、片方が壊れていても復元します。 **Olivia と Contestia**（トーンと帯域のすべての組み合わせ、受信と送信）。 **THOR**（4、5、8、11、16、22）：同調はおおまかで良く、マルチパスに強い。
- **コンテスト**：ARI DX、CQ WW、CQ WPX、IARU HF、VHF、汎用；ナンバー、重複、Cabrillo、SO2R。Enter で記録、Esc でクリア。 コンテスト中は QSO バーでも受信ナンバーを入力でき、すべての QSO（FT8、CW、RTTY…）がコンテストに入ります。上部に進行中のコンテストが表示されます。 得点はコンテストのルール（CQ WW、WPX、ARI DX、IARU、VHF）で計算され、Cabrillo に入ります。CQ WW と IARU ではゾーンがプリフィックスから自動入力されます。 コンテスター向けツール：バンドマップ、入力中のコールサイン候補（1 文字違いの「もしかして」付き）、編集できる F1〜F4 メッセージ（{MYCALL} {CALL} {EXCH}）、ESM（Enter で CQ、ナンバー、TU を送信）。 ARI FT8 Activity Contest（IAC）もあります：QSO ごとに 1 点、マルチは 4 文字のグリッド。 無線機が接続されていない（CAT なし）ときは、コールサインの横でバンドとモードを手で選びます。 米国・カナダ以外の局向けの **ARRL International DX** もあります（W/VE 局 1 局 3 点、マルチは州とプロビンス）。上部に **次の大きなコンテスト** と日付：クリックで選択。ナンバー交換（ゾーン、ロケーター、出力）は自動で入り、前日に通知が届きます。
- **衛星と宇宙**：次のパス、ドップラー、ローテーターでの追尾と無線機の補正。軌道データは自動でダウンロードされます。 QO-100：ロケーターからの方向、LNB の傾き、ビーコン、ダウンリンク・アップリンク・LNB 出力の換算。
- **クラスターと伝搬**：フィルター付きのDXクラスターとReverse Beacon Network；スポットをクリックすると無線機がそこへ。太陽データとバンドコンディション。 NCDXF/IARU ビーコン：各バンドで今送信している局、距離と方位、あなたの大陸で実際に受信されたビーコン。 「今開いているバンド」：過去 30 分間にあなたの大陸で実際に受信された局をバンド×大陸で表示。 POTA・SOTA・WWFF の移動局スポットも追加でき、公園や山頂のリファレンスがログに入ります。 **24時間予報**：QSO の相手や世界の地域に向けて、どのバンドが何時に開くか。ITU-R P.533 モデルと CCIR マップ（VOACAP と同様、QTHome に内蔵）で、局の雑音（ITU-R P.372）を含めた各バンドの信頼度も表示します（本当に開いているかは「今開いている」のスポットで分かります）。その局へのスポットがないときは QSO バーにも表示されます。 **表示** で新しいエンティティだけ、またはそのバンドで未交信の局だけを選べます。DXCC エンティティは毎週自動で更新されます。 **電離層の電波経路**：予報の下に、バンド・ホップ数・時刻ごとの経路（スキップゾーン、相手に届く打ち上げ角）。
- **地図**：夜とグレーライン、スポット、あなたを聞いている局、EME、Es；スポットをクリックで交信へ。 「自分の QSO」でログの局の位置を表示します（緑 = 確認済み）。「あなたから開いている（推定）」でバンドを選ぶと、そのバンドが今あなたの局から届く地域が地図に色で示されます。
- **SDR**：RTL-SDRドングルの受信機、スペクトラムとウォーターフォール；クリックでその周波数を聞きます。 ドングルで **船舶 (AIS)**（地図と OpenCPN への NMEA）と **航空機 (ACARS)** も受信。 **RS41 ラジオゾンデ**（400〜406 MHz）も：位置・高度・速度、地図に軌跡。 **気象衛星 Meteor-M の画像（LRPT、137.9 / 137.1 MHz）**：パス中にカラーで受信し、lrpt フォルダーに自動保存。 **電波天文**：ドングルによる放射計（時間ごとの電力と平均スペクトル、CSV ファイル）：20.1 MHz の木星、太陽と月、1420.4 MHz の水素線（速度 km/s 表示）。 **航空機（ADS-B）**：1090 MHz の航空機を地図に表示し、相手のロケーターを入れると 2 m・70 cm・23 cm の航空機散乱に使える機体（距離、方位、仰角）を表示。
- **ローテーター**：角度、ロケーター、現在のQSOの方向に向けます。ロングパスも可能。
- **QTHome Chat**：アマチュア無線家のテキスト・音声ルーム、暗号化された個人メッセージ；サーバーには何も残りません。 **インターネット経由の APRS (APRS-IS)**：自局のコールサインで APRS メッセージ、近くの APRS 局を地図に表示（水色）。 **AREDN メッシュネットワーク**：ノードにつないだコンピューターで、到達できるノード、ネットワークのサービス、リンク品質を表示。 **AX.25 パケット通信**（Direwolf か TNC で BBS やノードに接続する端末）と **Meshtastic**（LoRa メッセージ、ノードを地図に表示）。 **EchoLink**：世界中の EchoLink レピーター・リンク・局と QTHome から直接交信（局リスト、音声、テキスト）、ほかのプログラムは不要；EchoLink で認証済みのコールサインと、ルーターで開けた UDP ポート 5198-5199 が必要です。
- **Winlink**：インターネットまたは VARA モデム（別途インストール）による無線でのメール：受信、送信、添付、非常通信用の ICS-213 フォーム。Winlink のパスワードはこのコンピューターにだけ保存されます。
- **ツール**：計算ツール、スミスチャート、アンテナラボ、パイルアップ練習、**コッホ法で CW を覚える**、国家試験クイズ。 **NanoVNA**：アンテナの SWR、インピーダンス、SWR 2:1 の帯域、短くするか長くするかのアドバイス。 **送信機の直線性**：SDR ドングルで測る 2 トーンテスト（IMD 3 次・5 次・7 次）、ダミーロードで。
- **接続**：QTHome が使うものすべてを、ランプ（緑 = 動作中）とボタン付きで表示：無線機（複数台、ネットワークの FlexRadio も）、SDR ドングル、各機能が使う無線機とオーディオ、外部プログラム（WSJT-X、fldigi、JS8Call、ロガー：QTHome を通して同時に接続）、GridTracker などへのデコード、電話、アクセサリー（送信シーケンサー、アンプ、アンテナ切替、バッテリー、気象、WinKeyer、USB パドル）。上のランプをクリックしても開きます。各機能の上のバーに、オン・オフと使う無線機が表示されます。 **SO2R**（接続）：同時に 1 台だけ送信するインターロックと、OTRSP プロトコルの SO2R ボックス（アンテナとマイクは送信中の無線機へ、ヘッドホンはコンテストで選んだ無線機へ）。 **Bluetooth** の無線機（IC-705、Bluetooth CAT アダプター）は先にシステムでペアリングします。シリアルポートになり、QTHome が USB と同じように見つけます。
- **設定**：自局、トランスバーターと S メーター、外観、言語、アクセシビリティ。**自局** では **使うバンドとモード**（「今交信できる局」とクラスターがそれに合わせます）と **通知**（新しいエンティティ、衛星の接近、「聞こえています」＝スポットに自局のコールサイン）も選べます。どのパネルでも表示されます。

**キオスクモード**（設定 › 外観）：展示会、クラブの部屋、デモ用。受信機能だけが残り、設定と送信は消えます（外部プログラムからもエンジンで禁止）。オンにしたときの PIN で終了します。

**電話**（接続 › 電話）：「電話から QTHome を使う」をオンにし、電話のブラウザでアドレスを開いて PIN を入力します。「外出先からも」をオンにすると、ルーターの設定なしにインターネット経由でどこからでも使えます。プログラムが自分で QTHome のサービスにつながり、秘密にすべきアドレスを表示します。電話からできること：周波数、モード、スポット、ログ。送信はできません。

**CW の改善に協力**（設定）：CW を聞いている間、QTHome の 2 つのデコーダーが受信内容を読み直し、コールサインを Reverse Beacon Network と照合します。送るのは疑わしい例だけで匿名です。

## 無料とPRO

受信、デコード、ログはいつでも無料です。QTHome からの送信、オートメーション、高度なコンテスト機能、オンラインQSLは PRO に含まれます。最初の30日間はすべて試せます。PRO は **年12ユーロ** で、サーバーと研究の費用をまかないます。

利用規約、プライバシー、14 日以内の返金：ヘルプ › 利用規約とプライバシー。

## うまくいかないとき

- **局をチェック**：**ヘルプ › 局をチェック…** でコールサイン、無線機、音声、時計、インターネット、ライセンス、アップデートを一度に確認し、問題ごとに直すボタンを表示します。
- **無線機が表示されない**：USBケーブルと無線機の電源を確認し、**接続 › 接続中の無線機 › 無線機を再検索**。
- **音が出ない**：Mac は システム設定 › プライバシーとセキュリティ › マイク › QTHome をオン。Windows は 設定 › プライバシー › マイク。
- **問題を報告**：**ヘルプ › 問題やアイデアを報告…** コールサイン、名前、住所なしで匿名で送られます。
